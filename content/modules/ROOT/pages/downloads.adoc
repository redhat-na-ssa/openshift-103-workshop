== On the Release Page

The release page, {release-page}, also has:

* `{workshop-name}-offline-{release-tag}.tar.gz`, the offline bundle: all the files above plus the built site in `www/`, to serve with any web server instead of the site image
* CycloneDX SBOMs of the site and tools images
