= OpenShift 103 Workshop

This workshop is for platform engineers who already run Amazon EKS or Azure AKS and now operate Red Hat OpenShift Service on AWS (ROSA) or Azure Red Hat OpenShift (ARO).

It is not a sales pitch.
Each section shows what is different, which differences matter in daily operation, where ROSA and ARO save you work compared with a platform you build yourself on EKS or AKS, and where the native service is the better tool.
